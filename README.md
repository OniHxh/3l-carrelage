# 3L Carrelage

Suivi des chantiers de 3L Carrelage : chantiers, photos, journal, tâches, heures, planning, clients, équipe, chiffre d'affaires.

**Ouvrir l'application :** https://onihxh.github.io/3l-carrelage/

- Démarrage instantané, fonctionne hors connexion.
- Les données restent sur l'appareil (téléphone, Mac). Rien n'est stocké dans ce dépôt.
- Synchronisation téléphone ↔ Mac chiffrée de bout en bout (Gist GitHub privé), à activer dans Paramètres → Données & appareil.
- Sauvegarde : Paramètres → Données & appareil → « Exporter tout ».

Installer sur iPhone : Safari → Partager → « Sur l'écran d'accueil ».
